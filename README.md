#### Project Overview
Mytholohiya is an atmospheric text-driven roleplaying game rooted in classical Philippine folklore and ancient archipelagic animism.
Players navigate perilous regional encounters shaped by dynamic weather transitions, folklore wards, and modular narrative choices.
Every decision triggers responsive status checks, entity callbacks, and inventory consequences across an evolving mythic journey.

#### Core Features
* Modular Narrative Engine: Registry-driven substories and dynamic encounter selection powered by tags, affinity weights, and passive stat perception.
* Granular Equipment and Loadout System: Fourteen-slot paperdoll gear loadout tracking weight capacities, clothing layers, and folklore items.
* Folklore Warding Mechanics: Authentic mythological interactions including inside-out clothing illusions, salt rites, and ancestral talisman counters.
* Reactive Ambient Audio and Visualizer: Procedural Web Audio synthesizer featuring custom biomes, weather gradients, and interactive soundscapes.
* Turn-by-Turn Resolution Flow: Dedicated outcome screens with explicit continue checkpoints and full player choice autonomy.
